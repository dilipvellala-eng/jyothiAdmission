# Sample UI Screens

The React app includes these ready-to-run screens:

1. Login / Registration
   - Role-aware JWT sign-in
   - Parent/student self-registration
   - Seed credentials visible in `README.md`

2. Dashboard
   - Total, approved, pending, rejected, and draft counts
   - Application counts by class
   - Seat availability list

3. Multi-Step Admission Form
   - Step 1: Pupil details from the school admission form
   - Step 2: Parent/guardian details and mother name
   - Step 3: Previous school, TC/record sheet, class sought, medium, languages, vaccination, identification marks
   - Step 4: Document uploads
   - Step 5: Review and submit
   - Local auto-save and server-side draft save

4. My Applications
   - Parent/student status tracking
   - Submit draft
   - Download protected PDF with JWT

5. Admin/Staff Review
   - Search and status filter
   - Duplicate warning badge
   - Approve/reject decisions
   - Remarks
   - Protected PDF download
   - CSV export

6. Classes and Seats
   - Admin class setup
   - Total, filled, and available seat counts
